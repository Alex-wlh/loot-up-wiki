## How do you redeem Loot Up codes?

Current redemption instructions give this path:

1. Launch **Loot Up** in Roblox.
2. Select **Social** on the left side of the screen.
3. Enter or paste the code into the **Community Server Reward** field.
4. Select **Claim**.

Type codes exactly as shown. Published code guides note that Loot Up codes are case-sensitive, so a capitalization mistake can look like an expired code.

## Where can new codes appear?

## Why might a reported code fail?

Codes can expire, be replaced, or be limited. First check capitalization and the entry field; if it still fails, treat the source report as outdated and check the live game or official channels.
