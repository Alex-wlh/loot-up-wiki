## What is confirmed about Parchment in Loot Up?

Two code-guide sources record Parchment as part of historical reward bundles. Pro Game Guides and Roblox Den both list `AWAKENING`, `SORRY`, and `CLANUPDATE` with 100 Parchment in their archived code information. This confirms a reward-history connection, not that those codes still work or that Parchment drops from a particular activity.

## What use has been reported for Parchment?

In a creator’s beginner-to-pro video, the speaker says a third skill slot can be bought with Robux, real money, or Parchment after 17 days. That is a useful lead for players researching skill slots, but it is a video-source report rather than an official current system description.

Use the [Skills guide](/builds/best-skills) for the currently collected skill-system notes. Do not convert this one reported use into a claim that Parchment has only one purpose.

## What this page cannot answer yet

The available sources do not show a reliable normal acquisition location, drop table, quest requirement, or shop price for Parchment. For that reason this is a “uses and code reward history” guide, not a “how to farm Parchment” guide. A future update needs an official post, an in-game record, or another independent direct source before expanding the claim.
